# Code of Conduct

SkillRoll is a small project, and its conversations should stay useful,
welcoming, and easy to join.

## Our standard

We expect everyone to:

- be respectful and assume good intent while discussing the work;
- focus criticism on ideas, behavior, and evidence—not people;
- explain disagreement clearly and leave room to change their mind;
- welcome different backgrounds, communication styles, and levels of
  experience; and
- protect private information, credentials, and unpublished work.

Unacceptable behavior includes harassment, discrimination, threats,
personal attacks, deliberate disruption, sexualized attention, doxxing, and
publishing someone else's private information without permission. Repeatedly
ignoring project boundaries or using automation to flood issues and pull
requests is also not welcome.

## Enforcement

Project maintainers may edit, hide, close, or remove comments and issues;
request a pause; reject a contribution; or restrict participation when it is
needed to keep the project safe and workable. Decisions should be explained
when practical.

To report a concern privately, open an issue asking the maintainer for a private
channel without including sensitive details. Reports will be handled as
confidentially as the maintainer's tools and responsibilities allow.

This code applies in the repository, its issue tracker, pull requests,
discussions, and project spaces used for SkillRoll work.
