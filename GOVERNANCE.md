# Governance

SkillRoll is currently a single-maintainer project. The maintainer owns scope,
design, review, releases, and security response. There is no response-time or
merge-time guarantee.

Significant changes start with an issue that explains the user problem. Small
documentation, test, and bug fixes can go directly to a pull request when the
scope is clear. Decisions prioritize:

1. user value and fit with [PHILOSOPHY.md](PHILOSOPHY.md);
2. a small, understandable maintenance surface;
3. testability without secrets or fragile services;
4. clear behavior and security boundaries; and
5. available maintainer capacity.

Submissions may be deferred, split, rewritten, or closed when they are unclear,
duplicate existing work, or exceed the project's scope. Submission effort does
not determine priority. AI-assisted contributions follow the same review and
accountability standard as other work.

If regular contributors emerge, ownership areas or co-maintainers may be added
here.
