# PR overview

Select the important supplied facts and explain the change, validation, and
remaining questions. Use the renderer only for the fixed document skeleton;
the agent remains responsible for choosing truthful content. If facts are
missing, label the gap rather than inventing it.

Read [overview context](references/context.md) before formatting a document.
